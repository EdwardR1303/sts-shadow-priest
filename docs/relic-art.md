# Voidform relic artwork

The starter relic uses a transparent adaptation of WoW's `spell_priest_voidform` icon. The curled purple tendril and shadowy face form the relic's irregular silhouette. There is no square frame or opaque background. The game caches padded 128 x 128 and 256 x 256 textures for normal and enlarged displays.

## Generation prompt

Edited from the original icon with the built-in image-generation tool on October 23, 2026. No API/CLI fallback was used. Final prompt:

Use case: background-extraction / precise-object-edit. Edit target: the attached original World of Warcraft Voidform ability icon (spell_priest_voidform). Make it a Slay the Spire relic sprite. Preserve the recognizable curled violet void tendril and shadowy figure motif from the reference, its orientation, pink-purple highlights, and dark indigo interior. Cleanly extract and lightly refine this exact motif into a crisp painterly game-item cutout. Remove ALL rectangular icon background and corner/frame treatment. The result must have an irregular organic relic silhouette following the curled tendril and lower shadowy head/body, NOT a square, rectangle, medallion, badge, card, or token. Strong readable dark outer contour, a restrained violet rim light, simplified details legible at 64 pixels. ONE relic, centered with generous fully transparent padding (object occupies about 65 percent of the square canvas width and height). GENUINE TRANSPARENT ALPHA background, including inside the curl; no black backdrop, checkerboard, opaque panel, text, words, watermark, extra objects or extra tentacles. This is an adaptation of the actual icon, not an unrelated new relic design.
